# ADR-009: React + TypeScript staff console with white-label theming

Status: Proposed  
Date: 2026-09-27

## Context
Each tenant wants its own brand; the prototype established the layout.

## Decision
React + TypeScript, a small in-house design system (frontend/design-system), theme tokens per tenant. The API is the contract (OpenAPI).

## Consequences
Starts in Phase 1 week 3 once the first APIs exist.
